# tools

> Raccolta di tool personali per risolvere problemi specifici.

## Contenuto

- **dump_folder** → Dump ricorsivo di una directory in un singolo file testuale, con ordine deterministico e placeholder per i file binari.

## Convenzioni

- Ogni tool vive in una propria cartella ed è autosufficiente.
- Ogni tool include il proprio codice e la relativa documentazione.
